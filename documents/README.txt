DOSSIER DOCUMENTS — STRUCTURE
=============================

Place tes PDFs dans les sous-dossiers correspondants :

  documents/
    ft/             ← Fiches Techniques produits (FT-Mat-45.pdf, FT-Titane-Hydro-Mat.pdf, etc.)
    fdes/           ← FDES environnementales (FDES-Atelier-45-phase-aqueuse.pdf, FDES-Titane-Hydro.pdf)
    plaquettes/     ← Plaquettes commerciales gammes maison (Plaquette-Atelier-45.pdf, Plaquette-Titane-Hydro.pdf)
    partenaires/    ← Docs marques distribuées (Plaquette-KEIM.pdf, Plaquette-Chromatic-PPG.pdf, Plaquette-Theolaur.pdf)

Les nuanciers PDF restent dans /nuanciers/ (déjà en place).
